## 1. Voice Commands (#9)

**File**: `core/enhanced_voice_recognition.py`

### Integration Steps
1. Import in `ui/streamlit_app.py` (near your existing voice button):
   ```python
   from core.enhanced_voice_recognition import EnhancedVoiceRecognition
   ```

2. In your voice input handler:
   ```python
   vr = EnhancedVoiceRecognition(engine_ref=st.session_state.get('engine'))
   cmd, score, raw = vr.recognize(recognized_text)

   if cmd == 'score' and score is not None:
       st.session_state.engine.record_throw(score)
   elif cmd:
       result = vr.execute_command(cmd)
       if result.get('ui_update_needed'):
           st.rerun()
   ```

3. (Recommended) Add STT support:
   - Browser Web Speech API (custom Streamlit component)
   - Or local Whisper via `faster-whisper` / `openai-whisper`

4. Extend `COMMAND_PATTERNS` dict for custom commands.

## 2. Advanced Heat Maps (#15)

**File**: `core/advanced_heatmap.py`

### Integration Steps
1. Import:
   ```python
   from core.advanced_heatmap import generate_advanced_heatmap, HAS_PLOTLY
   ```

2. In Analytics tab (example):
   ```python
   throws_data = st.session_state.get('current_player_throws', [])  # list of dicts with x,y,score,visit

   if throws_data:
       fig, analysis = generate_advanced_heatmap(
           throws_data, 
           player_name=st.session_state.current_player.name,
           use_plotly=True
       )
       if fig:
           if HAS_PLOTLY:
               st.plotly_chart(fig, use_container_width=True)
           else:
               st.pyplot(fig)
       st.markdown(analysis)
   ```

**Tip**: Install `plotly` for the best interactive experience:
```bash
pip install plotly
```

## 3. Adaptive Bot Difficulty Scaling (#21)

**File**: `core/smartbot_autoscale.py`

### Integration Steps
1. Import:
   ```python
   from core.smartbot_autoscale import AdaptiveDifficultyScaler
   ```

2. In your game loop (after each leg or every 9–12 darts):
   ```python
   if st.session_state.get('adaptive_bot_enabled'):
       scaler = st.session_state.get('difficulty_scaler') or AdaptiveDifficultyScaler(current_bot_level=6)
       
       recent_scores = [t['score'] for t in game_state['recent_throws'][-12:]]
       adjustment = scaler.adjust_difficulty(recent_scores, force_adjust=True)
       
       if adjustment['adjustment'] != 0:
           st.toast(adjustment['message_for_player'], icon="🤖")
           # Update your DartBot instance
           current_bot = st.session_state.engine.bot
           if hasattr(current_bot, 'update_level'):
               current_bot.update_level(adjustment['new_level'])
           st.session_state.difficulty_scaler = scaler
   ```

3. Add a toggle in Settings: "Adaptive Bot Difficulty"

## 4. Extended Themes + Eye Comfort (#29/#30)

**File**: `core/extended_themes.py`

### Integration Steps
1. Import:
   ```python
   from core.extended_themes import get_enhanced_theme, get_all_enhanced_themes
   ```

2. In Settings tab:
   ```python
   theme_options = get_all_enhanced_themes()
   selected = st.selectbox("Theme", list(theme_options.keys()), format_func=lambda x: theme_options[x])

   eye_comfort = st.toggle("Eye Comfort Mode", value=True)
   oled = st.toggle("OLED Optimized", value=True)
   brightness = st.slider("Brightness", 0.6, 1.2, 1.0, 0.05)

   if st.button("Apply"):
       new_theme = get_enhanced_theme(selected, eye_comfort=eye_comfort, brightness=brightness, oled_optimized=oled)
       st.session_state.current_theme = new_theme
       st.rerun()
   ```

3. Apply `st.session_state.current_theme` to your dartboard drawing functions and page CSS.

## 6. Pressure Performance Index (#16) — NEW

**File**: `core/pressure_performance_index.py`

### Integration Steps
1. Import:
   ```python
   from core.pressure_performance_index import PressurePerformanceIndex
   ```

2. Initialize once per match/player:
   ```python
   if 'ppi' not in st.session_state:
       st.session_state.ppi = PressurePerformanceIndex(close_threshold=25)
   ppi = st.session_state.ppi
   ```

3. After every throw (in engine or scoring handler):
   ```python
   ppi.record_throw(
       score=last_score,
       was_ahead=(player_score > opponent_score),
       was_behind=(player_score < opponent_score),
       was_close=abs(player_score - opponent_score) <= 25,
       in_checkout_range=(remaining <= 170),
       leg_number=current_leg,
       visit_number=current_visit
   )
   ```

4. Display in Analytics:
   ```python
   stats = ppi.get_clutch_stats()
   st.json(stats)           # or build nice cards
   # Bonus: Feed ppi.get_pressure_heatmap_data() into advanced_heatmap.py
   ```
