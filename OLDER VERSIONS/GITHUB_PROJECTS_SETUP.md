# GitHub Projects & Milestones Setup for Dart Game Pro

## 1. Create GitHub Project (Recommended)

1. Go to your repo: https://github.com/Stijnman/Dart-app
2. Click **Projects** tab → **New project**
3. Choose **Board** layout
4. Name it: **Dart Game Pro Development**
5. Add the following columns:
   - Backlog
   - To Do
   - In Progress
   - Review
   - Done

## 2. Create Milestones

Go to **Issues** → **Milestones** → **New milestone**

Create these milestones:

### v2.4 - Voice & Polish (High Priority)
- Due date: ~2-3 weeks
- Description: Voice Commands, Advanced Heat Maps, Difficulty Scaling polish, Customizable Themes

### v2.5 - Competitive Edge (Medium Priority)
- Description: Knockout enhancements, Ladder League, Pressure Performance Index, Coaching Mode

### v2.6 - Ecosystem (Future)
- Description: AR, Streaming, Hardware integration, Cloud sync, etc.

## 3. Create Issues from Roadmap

For each high-priority feature, create an issue with:
- Title: e.g. "Implement Voice Commands (#9)"
- Labels: `enhancement`, `high-priority`, `roadmap`
- Milestone: Assign to correct version
- Add to the Project board

## 4. Recommended Labels

Create these labels in your repo:

- `roadmap`
- `high-priority`
- `medium-priority`
- `ai`
- `analytics`
- `ui`
- `voice`
- `theme`

## 5. Automation (Optional but powerful)

You can later add GitHub Actions or use the Project's built-in automation to move cards when issues are closed.
